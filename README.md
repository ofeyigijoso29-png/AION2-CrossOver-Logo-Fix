**Неофициальный обход зависания AION2 на стартовом логотипе под Rosetta, CrossOver и NotProton.**

На проверенной конфигурации игра прошла заставку, авторизацию и вход в лобби. Игрок подтвердил, что запуск работает. Это экспериментальный обход конкретного сбоя запуска; стабильность долгой игровой сессии и прирост FPS не проверялись.

## Для какой конфигурации

| Компонент | Поддерживаемый вариант |
| --- | --- |
| Mac | Apple Silicon с Rosetta 2 |
| CrossOver | **26.3.0.39832** |
| NotProton | **1.1.3**, уже установленный и подготовленный для этой версии CrossOver |
| Steam | Нативный Steam для macOS; AION2, App ID **3393110** |
| Установщик | Python 3.9+; Apple Command Line Tools нужны только для сборки из исходников |

Запуск проверен под Rosetta на Apple Silicon. Совместимость со всеми моделями Mac и версиями macOS не установлена.

Установщик сверяет SHA-256 двух файлов Wine и исходного скрипта запуска NotProton. Другая версия или уже изменённый скрипт будут отклонены. Не отключайте эти проверки ради принудительной установки.

## Быстрый старт

1. Установите CrossOver и [NotProton 1.1.3](https://github.com/NotProtonNot/NotProton/releases/tag/v1.1.3). В NotProton завершите установку компонентов и подготовку CrossOver.
2. В **Steam для Mac** выберите NotProton для AION2. Один раз запустите игру, чтобы создать её профиль, затем **полностью закройте AION2**. Успешный вход в игру на этом этапе не требуется.
3. Со страницы [релиза](https://github.com/ofeyigijoso29-png/aion2-crossover-rosetta-guard/releases/tag/v0.1.0) скачайте **AION2-Rosetta-Guard-v0.1.0-macos.zip** — готовый комплект с загрузчиком и установщиком. Проверьте `python3 --version`: требуется Python 3.9 или новее.
4. Распакуйте ZIP и запустите `install.command`. Через Терминал в распакованной папке можно выполнить `python3 installer.py install`.

Для сборки из исходников вместо готового ZIP нужны Apple Command Line Tools (`xcode-select --install`), затем:

```bash
git clone https://github.com/ofeyigijoso29-png/aion2-crossover-rosetta-guard.git
cd aion2-crossover-rosetta-guard
./install.command
```

Готовый ZIP содержит локально собранный загрузчик Wine с проверкой SHA-256, исходники и лицензию LGPL. **Source code (zip)** содержит только исходники. Если macOS блокирует скачанный загрузчик, используйте сборку из исходников; отключать защиту macOS не нужно.

После сообщения `Active for AION2 only` запускайте игру кнопкой **«Играть» в Steam для Mac**. Выбранным инструментом совместимости остаётся NotProton. Запуск Windows Steam внутри бутылки CrossOver не использует этот установщик.

## Что установщик делает

Он создаёт отдельные копии подготовленного Wine и профиля AION2, затем устанавливает готовый загрузчик из ZIP либо собирает его из исходников:

```text
~/Library/Application Support/AION2RosettaGuard/
├── runtime/                 отдельный Wine с локально собранным загрузчиком
├── compatdata/pfx/          копия профиля AION2
├── launcher/               отдельный каталог запуска и диагностический лог
├── notproton-run.original   резервная копия скрипта NotProton
└── state.json              сведения для проверки и отката
```

Затем меняет маршрутизацию в скрипте NotProton **только для AION2**. Остальные игры продолжают использовать исходный путь. Установленная CrossOver.app, исходный подготовленный Wine, файлы игры и исходный профиль сохраняются. Копирование использует механизм copy-on-write macOS на совместимой файловой системе.

После установки AION2 использует **скопированный профиль**: новые локальные настройки и данные появляются в `compatdata/pfx`. При откате игра снова использует исходный профиль. Откат сохраняет копию, но не объединяет её с исходным профилем; синхронизация Steam Cloud между этими профилями не проверялась.

Не удаляйте каталог `AION2RosettaGuard`, пока обход активен. Все операции выполняются без `sudo`. FPS, графика, оверлей и параметры синхронизации этим проектом не настраиваются.

## Проверка, откат и повторное включение

```bash
./status.command       # состояние и только диагностические строки обхода
./uninstall.command    # сначала закройте игру; восстановить исходный запуск
./activate.command     # снова включить уже подготовленную копию
```

Откат сохраняет отдельный Wine и профиль, поэтому повторное включение не пересоздаёт настройки. Если NotProton или пользователь изменил скрипт после установки, автоматический откат откажется его перезаписывать. Резервная копия останется доступна.

Обновление NotProton может заменить скрипт запуска. Сначала проверяйте состояние; не применяйте этот релиз поверх другой версии Wine или NotProton.

Для нестандартных путей:

```bash
python3 installer.py install \
  --runtime '/путь/к/подготовленному/CrossOver' \
  --tool '/путь/к/compatibilitytools.d/notproton-26.3/run' \
  --prefix '/путь/к/steamapps/compatdata/3393110' \
  --root '/путь/к/отдельной/установке'
```

`--prefix` указывает на каталог `3393110`, **не** на вложенный `pfx`. С тем же `--root` выполняйте `status`, `uninstall` и `activate`. Для проверки сборки без изменения активного запуска есть команда `prepare`.

## Как устроен обход

В отдельном воспроизводящем тесте переключение в 32-битный сегмент с выполнением CPUID на границе 4 ГиБ зависало внутри Rosetta до доставки исключения Wine. Отказ в выделении памяти для этого пути позволяет избежать перехода. В рабочем запуске AION2 был зарегистрирован такой отказ, затем игра перешла к авторизации и лобби. Это поддерживает гипотезу о проблемном пути, но не доказывает все внутренние причины зависания игры.

В локально собранный загрузчик Wine встроен узкий перехват `NtAllocateVirtualMemory`. Он отказывает только при совпадении **всех** условий:

| Параметр | Значение |
| --- | --- |
| Процесс | `NtCurrentProcess()` |
| Базовый адрес | `0xffff0000` |
| Размер | `0x10000` — 64 КиБ |
| ZeroBits | `0` |
| Тип | `0x3000` — `MEM_RESERVE | MEM_COMMIT` |
| Защита | `0x40` — `PAGE_EXECUTE_READWRITE` |
| Ответ | `0xc0000018` — `STATUS_CONFLICTING_ADDRESSES` |

Все другие вызовы передаются исходной функции. Это **ошибка выделения памяти**, а не эмуляция процессора или подмена успешного результата. Код не отключает NCGuard и не изменяет исполняемые файлы игры.

Перед установкой перехвата проверяется SHA-256 всего `ntdll.so`, структура таблицы системных вызовов и сигнатура функции. Код создаёт копию таблицы в памяти, заменяет одну функцию и делает копию доступной только для чтения. Файл `ntdll.so` на диске не изменяется. Обход активируется только под Rosetta для App ID `3393110` либо для отдельного теста с `AION2_GUARD_TEST=1`.

## Что проверено

- Сборка публикуемого загрузчика на тестовом Mac.
- Обычный CPUID и доставка обычного исключения INT3 в Wine.
- Выделение памяти для данных на границе 4 ГиБ, динамической исполняемой памяти и обычной фиксированной исполняемой памяти: работают.
- Только целевое выделение RWX отклоняется с Windows error **487**.
- Воспроизводящий тест с `iretq` прекращается на отказе выделения, не входя в проблемный переход.
- Маршрутизация только AION2, безопасная обработка путей, сохранение профиля и отказ от перезаписи изменённого запуска проверяются тестами установщика.
- Реальная игра: новая последовательность этапов **Title → Platform login → Login server → Lobby**, плюс подтверждение игрока.

Команды для разработчиков и подробные границы проверки: [TESTING.md](TESTING.md). Этот обход не обещает исправление любого вылета или зависания.
